FIVE WAYS TO MAKE IT YOUR OWN

五种关系，五套操作方式。

这一轮，共享的只有经历与演示糕点数据。
每一版有自己的导航、输入方式、返回动作和完成反馈。

01

住进去

FIRST-PERSON ROOM

靠近物件，直接在物件表面操作。

靠近日历 → 在手账上写字 → 退回房间
↗ 02

造出来

TOP-DOWN BUILDER

选择物件、预览位置，用自己的布局组织生活。

拿取 → 放置与旋转 → 组合成一个角落
↗ 03

拿起来

TACTILE JOURNAL

纸笺有摊开、折起、夹进手账与放回抽屉的状态。

抽一张纸 → 写与盖章 → 折起或收好
↗ 04

走近

SEMANTIC MEMORY MAP

远处是主题，近处是节点，再近一点才读到原文。

漫游 → 分级缩放 → 在局部留下坐标
↗ 05

说出来

DIALOGUE THEATRE

不同回应进入不同分支；你确认以后，话才变成纪念物。

回应 → 修改原话 → 决定是否留下
↗

用同一件事比较它们

分别试一次“留下今天的一件事”，再找回它、看看糕点。观察哪种方式最自然，而不只是先比较背景好不好看。

本轮边界

桌面 Web 原型，本地浏览器保存，请在同一标签页切换，多标签同步暂未实现。对话舞台使用明确标注的脚本分支，未连接高老师或真实 AI。没有真实支付、账号或云端资产系统；奖励与价格仍为演示假设。
